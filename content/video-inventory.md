## How to log a clip

For every existing video Robert can identify, add a row in the right
track table. **Use one line per clip.** Don't get fancy. If the clip
exists but topic is unclear, log it anyway — Panos / Alejandro can
review later.

**Required columns:**
- **Clip ID** — temporary name (V001, V002, …) until proper naming is locked
- **Storage location** — Phone? Drive folder? SD card? "Santiago's hard drive"?
- **Approx date recorded**
- **Track** — 1.0 / 2.0 / 3.0 (or "unsorted")
- **Triad leg** (2.0 only) — Solids / Liquids / EM
- **Topic** — one short line
- **Status** — RAW / EDITED / PUBLISHED
- **Notes** — anything else (length, quality, b-roll, missing audio)
