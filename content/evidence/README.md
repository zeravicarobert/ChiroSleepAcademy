# CSA Evidence Library

**Purpose:** One place for the outside research papers CSA cites, each with a
verified citation and clear rules for using it *without overclaiming*. As new
papers come in, add one file per paper and a row to the table below.

This library supports CSA's authority-building and the "Data & Outcomes" pillar
(Master Summary §12 Pillar 6, §13). These are **external** papers used as
*context* — separate from CSA's own outcomes data, which lives in the **CSA
Outcomes Registry** (Master Summary Level 5) / the `/funnel` trackers.

---

## The rule for every citation here (non-negotiable)

Applies the red lines (`CLAUDE.md` §5) and Master Summary §14 positioning
boundaries to research:

1. **Verify before you cite.** Confirm title, journal, DOI, authors, and the
   study's *actual* finding before it goes in any post or page. (Both current
   assets were web-verified 2026-07-16.)
2. **Human vs. animal, living vs. postmortem, anatomy vs. function** — state it.
   A mouse study, a cadaver study, or a model simulation is not a human clinical
   result.
3. **"Gives better questions," not "proves."** These papers make CSA's questions
   biologically serious. None proves chiropractic/VAET does anything clinically.
4. **Never claim:** cure of sleep apnea; that adjustments/VAET move CSF, lymph,
   or "pump/clean" the brain; that a mechanism is proven when it's hypothetical;
   or that a paper validates chiropractic philosophy.
5. **Additive, not anti-medical.** Position as "conventional models are
   *incomplete*," never as "CPAP/dentistry/medicine/surgery are wrong."
6. **Each asset carries its own "Do NOT say" list.** Read it before writing copy.
