# Session Notes — 2026-07-27

## Idea captured this session: CSA Broadcast Channel (modeling Robert Garza)

**Origin:** Robert saw a broadcast channel run by "Robert Garza" (559 members,
one post seen by 1.2K). It's a **one-way channel** — only the creator posts;
members can only react and vote in polls. Garza drops a single post
("🚨 National Call To Action 🚨") with one Zoom link and people pile in.

**Decision:** Model this format for CSA — a **Structural Airway Chiropractic
broadcast channel** where Dr. Z is the only voice and periodically drops a
genuine teaching invite / live Zoom (on-brand, no fear-based hype).

**Why it fits CSA:**
1. One-way = authority. Every message reads as *the* signal — perfect for a
   doctor-teacher category-builder.
2. Low management overhead. React/poll-only means almost no moderation
   (good for Peter as ops).
3. One clear ask per post — a single Zoom link, a reason to show up now.
4. Reactions + polls = built-in feedback loop on what DCs want next.
5. It's a funnel with a front door: outreach → channel → Zoom → offer.

**On-brand translation:** No fear-based "call to action." Genuine teaching
invites, e.g. *"Join me live: how the HST becomes the new X-ray."*
