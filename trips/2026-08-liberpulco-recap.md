## 4. Handling the Inbound VAET Inquiries

These are the highest-value item on this page — real people asking to pay for
something Robert already does.

**Do not run this in DMs.** Move each inquiry into the existing CSA pathway
(CLAUDE.md § 8) so the clinical and ethical structure stays intact:

> DM → free Alignment Call (Zoom) → sleep/airway history + screen →
> HST if indicated → findings → what VAET can and cannot address → proposal

**Guardrails for every one of these conversations (CLAUDE.md § 5):**

- VAET does **not** cure sleep apnea. Never imply it does.
- Robert does **not** diagnose OSA. The role is structural.
- Never position VAET against CPAP, oral appliances, or surgery. It is
  *additive* — the structural layer alongside their existing care.
- If someone is already on CPAP or under a physician's care, the message is
  "keep working with them, let's look at the structure underneath."
- Be explicit that a mini-clinic or event session is a **test experience**, not
  a treatment plan — same framing as the Tecopa Step 4 trial.

A ready-to-adapt reply template lives at
`outreach/inbound-vaet-inquiry-template.md`.
