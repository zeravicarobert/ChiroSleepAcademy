# 6. THE STRUCTURAL BREATHING SYSTEM

The project has developed a working model in which breathing involves multiple coordinated layers.

## 6.1 Central controller

The brainstem, particularly the medulla and pons, organizes automatic breathing.

A project infographic summarized the model as:

> **The medulla is the breathing rhythm engine. The pons is the pattern shaper.**

The related uploaded visual was created specifically to communicate the brainstem breathing controller and the distinction between respiratory rhythm and pattern shaping.

---

## 6.2 Chemical sensors

The project's simplified educational language is:

* The carotid bodies are blood-oxygen alarm sensors.
* Medullary chemoreceptors are primarily CO₂/pH sensors.

An uploaded infographic was created to communicate these concepts simply.

---

## 6.3 Respiratory motor pathways

The project identifies:

* Phrenic nerve, C3–C5 → diaphragm
* Intercostal nerves → rib-cage muscles
* Accessory pathways → scalenes, sternocleidomastoid, and abdominal muscles during increased demand
* Hypoglossal nerve → tongue-dilator function
* Vagal and glossopharyngeal-related pathways → pharyngeal and laryngeal control

An uploaded educational graphic captures this respiratory motor-pathway overview.

---

## 6.4 Upper-airway motor control

For sleep apnea, the tongue and upper-airway dilator system matter because the diaphragm may attempt to draw air through an airway that is mechanically narrowing or collapsing.

The project specifically highlights the hypoglossal nerve and tongue-dilator system.

---

## 6.5 Mechanical effectors

The working CSA model includes:

* Diaphragm
* Rib cage and intercostals
* Abdominal wall
* Tongue
* Soft palate
* Pharyngeal dilators
* Laryngeal stabilizers
* Lungs and airways
* Stretch receptors
* Irritant receptors
* Mechanoreceptor feedback
* Cranial and cervical structure
* Jaw and facial relationships
* Posture and gravitational orientation

The project's simplified formulation is:

> **The breathing-control system must coordinate the airway valve, tongue posture, diaphragm pump, rib-cage mechanics, and oxygen/CO₂ chemistry.**

This concept was incorporated into an uploaded mechanical-effectors infographic.

---

## 6.6 Loop gain

Loop gain has been developed as an educational topic for CSA.

The intended public explanation should remain simple:

> **Loop gain describes how strongly the breathing system reacts when oxygen or carbon dioxide moves away from its target. A system that overreacts can become unstable.**

An uploaded infographic was specifically revised toward a fifth-grade comprehension level.

# 14. LEGAL, CLINICAL, AND REPUTATIONAL PROTECTION

This project cannot be separated from compliance.

## 14.1 SDI scope and documentation

The uploaded plan expressly warns that chiropractic SDI certification should remain within California chiropractic scope and recommends attorney confirmation before aggressive scaling.

Uploaded SOAP-note materials demonstrate the related documentation problem:

* Some notes contain only documented telehealth findings.
* Some versions include added observations such as alertness, orientation, coherent history, or reported functional limitation.
* Other versions contain blank objective and assessment sections.
* The files include patient-identifying and protected health information.

The "documented data only" versions explicitly avoid inventing examination findings that were not performed.

This principle should guide both clinical operations and social-media content:

> **Never convert an assumption into a documented finding. Never convert a clinical hypothesis into a public fact.**

Patient files should never be repurposed into public content without proper authorization and de-identification.
