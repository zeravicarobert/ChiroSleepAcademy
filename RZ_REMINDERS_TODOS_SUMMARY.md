# 10. DIFFERENCE BETWEEN A PROJECT LIST AND AN ACTUAL REMINDER

A central distinction in this folder is:

### Writing something in the project does not automatically create a notification.

The folder can preserve and organize:

* Tasks
* Plans
* Priorities
* Dates
* People
* Follow-ups
* Routines

However, an item that must actively alert Dr. Z at a particular time needs to be created as a scheduled reminder or task.

Examples:

* "Call Dr. Doreo tomorrow at 10:00 a.m."
* "Remind me every Friday to review unpaid EDD patients."
* "Remind me in two weeks to check whether Dr. Petrie reordered the HST."
* "Every weekday at 12:30 p.m., review Jane's handoff."
* "On the first of each month, audit subscriptions."

This project should therefore maintain two parallel concepts:

1. **The master task and project record**
2. **The actual scheduled notification**

Important or time-sensitive tasks should include both.

# 11. RECOMMENDED TASK RECORD FORMAT

Each actionable task should ideally contain:

**Task:**
A clear verb-based action.

**Project:**
EDD SDI, CSA, VAET, personal, legal, family, property, etc.

**Owner:**
Dr. Z, Jane, patient, attorney, EDD, colleague, or other person.

**Status:**
Next action, delegated, waiting, scheduled, completed, canceled, or parked.

**Priority:**
Critical, current sprint, routine, or someday.

**Due date:**
A real date when one exists.

**Reminder:**
Whether a scheduled notification has been created.

**Person or organization:**
Who the task involves.

**Last action:**
What most recently happened.

**Next action:**
The very next physical or administrative step.

**Supporting link or document:**
ChiroCat file, Google Drive file, email, form, website, or note.

**Notes:**
Context necessary to understand the task later.

This format reduces vague entries such as "supplements," "website," or "call doctor."

# 13. DECISION RULES FOR NEW TASKS AND IDEAS

When a new item is added, it should be classified using the following logic:

## Do It Now

Use when the task is brief, necessary, and can be completed immediately without disrupting a more important activity.

## Schedule It

Use when the action must occur at a specific date or time.

## Add as Next Action

Use when it belongs to an active project but is not scheduled.

## Delegate It

Use when Jane or another person can properly complete it.

## Waiting For

Use when Dr. Z cannot act until another person or organization responds.

## Park It

Use when the idea is worthwhile but not part of the current sprint.

## Delete It

Use when it is obsolete, duplicative, unnecessary, or no longer aligned.

The most important discipline is that every idea should not become an active project.
